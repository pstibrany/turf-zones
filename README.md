# Turf Zones

Live [Turf](https://turfgame.com/) zone ownership map — static page, no backend.
Calls the public Turf API v5 from the browser.

**→ https://pstibrany.github.io/turf-zones/**

Also here: `turf-exporter`, a Go daemon that tracks the Hovedstaden (region 172)
top list as Prometheus metrics and logs every takeover. `go run . -help` for the
flags; see [TURF-API.md](TURF-API.md) for what the API can and cannot do.
